# SaveMAX Brain

Purpose: lead research, qualification, and sales preparation. This is a local AIS-OS workspace, not the SaveMAX application.

## Start using it

Open this folder as a project in Codex: D:\ROCRE\softwares\Savemax\brain

Example request: Find 20 leads for [offer], targeting [customer type] in [region]. Include source links and explain why each is a fit.

## Workspace routes

- context/purpose.md: confirmed scope
- context/about-business.md: business facts and unknowns
- context/priorities.md: current setup priorities
- workflows/lead-research.md: research process
- leads/leads.csv: lead tracker, initially empty
- connections.md: connection status
- references/voice.md: writing defaults

Six bundled skills are available from .agents/skills when this folder is opened in Codex. Full personal onboarding, external integrations, scheduled jobs, and the optional 3D visualizer are not configured.

## 3D interface
Installed in apps/3d-brain. Open http://localhost:4640. To restart: change into apps/3d-brain and run node serve.mjs.
